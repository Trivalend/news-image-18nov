A program that draws a newspaper front page summing up the world's news of Wednesday 18 November 2026: the US-Iran escalation in the Gulf, the Kerch Bridge strike, the Shenzhen trilateral summit, Ebola in DR Congo, Gaza's winter, COP31 and the day's briefs — as a single 1024x1024 PNG, drawn from scratch with a hand-written 5x7 bitmap font and a pure-stdlib PNG encoder. No network, no randomness: two runs write byte-identical output.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
